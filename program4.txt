;--------------------------------------
;Vole Machine program ( Jump if equal ) 
;Purpose : Load two equal numbers ( 5 and 5),
;jump over one instruction when they are equal,
;and display the result (A) on the screen.
;--------------------------------------

2005 ; Load the first number (5) into register 0
2105 ; Load the second number (5) into register 1
2241 ; Load 41 ( the letter A) into register 2
B10A ; if R1 equals R0 , jump to address 0A
2242 ; Load 42 (the letter B) into register 2 (skipped when the jump happens)
32FF ; display the result of R2 on the screen
C000 ; Halt the program
